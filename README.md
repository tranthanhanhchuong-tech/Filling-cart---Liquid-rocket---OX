# Filling-cart---Liquid-rocket---OX
A light weight cart carries liquid fuels, electrical box, pluming system and capable of empty and refuel the rocket. Can be operate manually or hand free



# Overview

This project develops a movable ground-support cart for equipment used to fill a rocket’s propellant tanks with nitrous oxide (N₂O) and ethanol.

The repository records requirements, design options, CAD models, piping and instrumentation diagrams (P&IDs), component selections, calculations, and review results.



# Project Status

Requirements definition and concept development.

Previous sketches and component suggestions are preliminary. Final dimensions, materials, components, and operating procedures remain subject to engineering review.



# Current Requirements

Carry one N₂O supply cylinder.

Carry one ethanol supply vessel.

Carry one electrical enclosure.

Carry one pneumatic and/or hydraulic panel; system type remains to be confirmed.

Keep the complete, fully loaded cart below 1,000 lb (approximately 454 kg).

Accommodate travel over gravel, rocky ground, grass, and sand.

Receive electrical power from a separate generator; the generator is not carried on the cart.

The mass limit includes the frame, wheels, restraints, supply containers and contents, equipment, plumbing, wiring, and mounting hardware.
